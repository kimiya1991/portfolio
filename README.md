# Kimiya Jafarpor - Portfolio

Professional portfolio for Kimiya Jafarpor, an AI and Machine Learning Developer based in Tehran.

## Run locally

1. Install Node.js 22 or newer.
2. Open this folder in VS Code.
3. Run `npm install` in the terminal.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Publish with GitHub Pages

1. Push this complete folder to the `main` branch of `https://github.com/kimiya1991/portfolio`.
2. Open the repository on GitHub and select **Settings > Pages**.
3. Under **Build and deployment**, choose **GitHub Actions** as the source.
4. Open the **Actions** tab and wait for the deployment to finish.

The public website will be available at:

`https://kimiya1991.github.io/portfolio/`

## Main files

- `app/page.tsx` - Portfolio content and page structure
- `app/globals.css` - Complete responsive visual design
- `app/layout.tsx` - Metadata, fonts, and shared layout
- `public/` - Portrait, social card, and static assets
- `.github/workflows/deploy.yml` - Automatic GitHub Pages deployment
